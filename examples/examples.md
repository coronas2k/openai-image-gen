# Example prompts

Use these prompts as starting points and adjust style, aspect ratio, and detail for your workflow.

> Note: OpenAI is usually the better choice for photorealistic or highly detailed image generation. Gemini is often better for quick iterations and conversational refinement.

## Game Assets

Focus on keywords like **seamless**, **tileable**, and **game asset** when generating production-ready assets.

- **Seamless stone floor texture**  
  Prompt: `Create a seamless, tileable top-down stone floor texture for a fantasy dungeon game asset, even lighting, readable grout lines, no perspective, no focal object.`  
  Recommended settings: size `1024x1024`, quality `high`  
  Provider suggestion: OpenAI for detail, Gemini for fast texture variations.

- **Pixel-art forest tileset**  
  Prompt: `Generate a tileable pixel-art forest ground game asset with grass, dirt patches, and small flowers, seamless edges, 2D RPG style, clean readable shapes.`  
  Recommended settings: size `1024x1024`, quality `medium`  
  Provider suggestion: Gemini for iteration, OpenAI for more polished final output.

- **Mobile game gem icons**  
  Prompt: `Design a set of colorful mobile game asset icons featuring ruby, sapphire, emerald, and gold coin rewards, transparent-style composition, clean outlines, high contrast, UI-ready.`  
  Recommended settings: size `1024x1024`, quality `high`  
  Provider suggestion: OpenAI.

- **Sci-fi crate sprite sheet concept**  
  Prompt: `Create a game asset concept for modular sci-fi cargo crate sprites, front-facing, clean silhouette, metallic panels, warning decals, consistent lighting, suitable for extracting sprites.`  
  Recommended settings: size `1536x1024`, quality `high`  
  Provider suggestion: OpenAI for clarity, Gemini for rapid visual direction changes.
